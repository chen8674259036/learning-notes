Part 01 · Pitfalls

我踩过的坑

1

打出了中文标点

我输入print{Hello,Agent！" }
SyntaxError: invalid character '！'
原因中文输入法状态下打的标点全是中文的，Python 只认英文标点。
写代码前先把输入法切成"英"（按 Shift）。中文（错）：（）“”！　英文（对）：()""! ,
2

括号用错形状

我输入print[''hello,Agent!''}
SyntaxError: invalid syntax
print 后面必须圆括号 ( )，文字用英文双引号 " "，结尾是 )。
3

把两句话挤在一行

我输入name="小明"print(name)
SyntaxError: invalid syntax
原因Python 一次只听一句话。第六课又踩了一次（两个 print 挤一行）。
一行一个动作。
4

行首多了空格（踩了三次！）

我输入 age = 18、 if name=="BABA":、 poem = r.json()
IndentationError: unexpected indent（意外的缩进）
原因在 >>> 后面输入，行首绝对不能有空格。复制粘贴时最容易带上前导空格。
顶格打。开头多了空格就按 Backspace 删掉。
5

在 Python 里面又输入 python

我输入>>> python
NameError: name 'python' is not defined
>>> = 已在屋里；C:\> = 在屋外。屋外才用 python 进屋。
6

if 的格式不完整

我输入ifname==
SyntaxError: invalid syntax
if 空格 name 空格 == 空格 "内容" 冒号，例：if name == "baba":
7

if 结尾忘了冒号

我输入if name=="BABA"
SyntaxError: expected ':'
if 那一行的结尾必须有英文冒号 : 。
8

把 >>> 提示符也打进去了

我输入>>> >>> if name=="BABA":
SyntaxError: invalid syntax
永远不要输入 >>>，只输入它后面的内容。
9

大小写不一致（踩了两次）

我输入"BABA" vs "baba"；R.TEXT vs r.text
原因Python 区分大小写：baba ≠ BABA，R ≠ r，text ≠ TEXT。
名字必须一字不差（包括大小写）。
10

exit() 拼错

我输入exin()
NameError: name 'exin' is not defined. Did you mean: 'exit'?
退出 Python 用 exit()。
11

else 拼错 + 小弟没缩进

我输入eise:print(...)
else 中间有个 l；if/else 的小弟要缩进。
12

ren 改名漏了空格

我输入ren myfirst.pynihao.py
ren 旧名字 新名字（中间空格）。
13

第六课新坑：网址丢了 https://

我输入requests.get("v1.jinrishici.com/all.json")
MissingSchema: Invalid URL ... No scheme supplied.
原因网址要有"门牌前缀" https://，告诉程序用什么方式去取。
网址 = https:// + 地址，一个都不能少。
14

第六课新坑：标签名拼错

我输入poem["prigin"]、r.txt
KeyError: 'prigin' / AttributeError: ... no attribute 'txt'
原因标签名和属性名都要照着数据里写的一字不差。
名字从哪看？r.text 的原始数据里写着，照着抄。
15

第七课新坑：网址只写了 "Chat"

我输入requests.post("Chat", json=data)（连续三次）
MissingSchema: Invalid URL 'Chat'
原因地址不完整：只有入口名，没有完整地址 http://localhost:11434/api/chat。
地址 = 服务地址 + 端口 + 接口路径，缺一不可。别按 ↑ 重复旧命令，出错先按 Ctrl+C 清空。

其他小插曲

Ctrl+C 打断 if 块（KeyboardInterrupt）→ 重输就行。
提示词和输入连在一起（njsmmzbaba）→ 小瑕疵，不影响。
引号里多打了个空格 → requests 会自动清理，但别养成习惯。
oilama 拼错 ollama → 差一个字母。手打容易错，能用复制粘贴就别手打。
Part 02 · Questions

我问过的问题

（ ）" 是这个吗？
那是中文括号，Python 要英文的 ( ) " "。
怎么打 ( ) " "？
输入法切"英"：( = Shift+9，) = Shift+0，" = Shift+回车键左边。
print 是什么意思？
"喊话"。把括号里的内容显示在窗口里。
name 是什么？
盒子的标签（自己起名），重要的是 = 右边装的内容。
逗号分中文和英文吗？
分！写代码一律英文逗号 ,。
print("你好", name) 是什么意思？
喊两样：带引号的原样喊，不带引号的去盒子取。
else 是什么？
"否则"。if 不成立时走 else。if 和 else 是一对搭档。
哪里有第五行？
正确代码 5 行，自己写的 4 行是 else 和 print 挤一起了。
else 和 print 写同一行有影响吗？
Python 允许（单行写法），但建议拆开：一行一个动作。
MYFIRST.py 名字可以改吗？
可以，只要 .py 结尾。命令行改名：ren 旧名字 新名字。
怎么进入 Python？
黑窗口输入 python 回车；看到 >>> 就是进来了。
requests 是什么？
上网工具包。import 拿进来，requests.get("网址") 去取数据。
r 是什么？为什么要 =？
r 是你给取回来的数据起的名字；= 是"接住并保存"，不接住数据就丢了。
为什么用方括号 [ ]？
圆括号给命令用，方括号给"从盒子按标签取"用：poem["content"]。
标签名怎么知道的？
不是编的——r.text 的原始数据里写着（content、author、origin…），照着抄。
requests.post 是什么？
HTTP 请求方法 post = 提交。把数据（json=data）提交给服务器，服务器处理完返回结果。
stream 是什么？
"流"。stream: False = 非流式，AI 一次把完整回答返回；True = 流式，边生成边发（打字机效果）。
Chat 是什么？为什么还要指定？
chat = 聊天，是接口的功能入口（/api/chat）。data 是内容，入口是通道，两者都要。去错窗口办不成事。
message 和 content 是什么？
message = AI 回复的消息，content = 消息里的文字内容。请求里 user.content = 你问的，响应里 message.content = AI 答的。
请求和响应为什么是两回事？
请求（data）= 你说的话；响应（r）= AI 的话。AI 不会把你问的再抄一遍，它只返回自己的回答。

Part 06 · Lesson 7

第七课：程序驱动 AI 对话

程序问 · AI 答
你（user）：你好
AI（assistant）：你好！有什么问题或者需要帮助的吗？
★

四段核心代码（ai.py）

第1段import requests —— 拿进上网工具包
第2段data = {"model": "qwen2.5:7b", "messages": [{"role": "user", "content": "你好"}], "stream": False} —— 打包请求：用哪个模型、问什么、一次说完
第3段r = requests.post("http://localhost:11434/api/chat", json=data) —— 发送 POST 请求，r 接住响应
第4段print(r.json()["message"]["content"]) —— 拆响应：message 层 → content 层，打印 AI 的回答
核心概念：请求（data）= 你说的话；响应（r）= AI 的话。两个信封，别混。
